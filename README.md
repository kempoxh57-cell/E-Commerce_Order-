# React.js E-Commerce Practical Exercise Application

This project is a complete implementation of the E-Commerce practical exercises including:
1. **Practical Exercise 1**: 4 Products (Laptop $650, Mouse $15, Keyboard $25, Monitor $120), Add to Cart button, and a full Shopping Cart page (View, update QTY, remove item, subtotal & grand total, Proceed to Checkout).
2. **Practical Exercise Checkout**: Customer information form (First name, Last name, Email, Phone, Address), validation for required fields, shipping method options, real-time order summary & grand total calculation, and Place Order button.
3. **Slide 28: Practical Exercise 3 Order Confirmation**: Order Placed Successfully message, Order ID (`ORD-0001`), Customer name, Order date, Ordered products list, Total amount, and Order Status (`Pending`).
4. **Practical Exercise Database Design**: Visual ERD Diagram connecting Customers, Categories, Products, Orders, and Order_Items, complete with schema definitions and SQL DDL script.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:5173/](http://localhost:5173/) in your browser.
